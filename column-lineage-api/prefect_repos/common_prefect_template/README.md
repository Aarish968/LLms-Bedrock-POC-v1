# Usage

Install [uv](https://github.com/astral-sh/uv)

Ensure you have authenticated with AWS so you can fetch the git repository.

``cd`` to the directory you want to create the project in and run the following command:

```bash
uv run --with cookiecutter cookiecutter https://git-codecommit.us-east-1.amazonaws.com/v1/repos/common_prefect_template
```

And follow the prompts.
